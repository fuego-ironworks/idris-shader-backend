# Runner division and structured-IR acceptance

Owned host and Android C runners contain literal `÷`, parsed directly by ICK
`c61e448251744a2f40ad743ebef1a027bdcd2f9d` through pinned ai-ci
`903b2cb27ea572c9c6cb2ffa9f39e0fbf06ec9f8`. NDK r27c retains Android API21
assembly/platform linking. Dynamic Android executable C uses `-fPIC` and the
link remains `-pie`; the completed runner is rejected if it contains a COPY
relocation. Ordinary Idris source and generated GLSL retain their own syntax.

The current main branch's structured-IR migration had left stale golden files,
unrolled-loop expectations, and mock emitters consuming the removed `bindings`
field. The repair preserves structured source IR and emits an operand select
only when both branch bodies are empty. Nonempty branch bodies remain guarded.
The negative-radius assertion checks the actual condition/radius expressions
instead of depending on a temporary number. Compiler-sphere, disc-reveal and
two primitive shaders were regenerated by the registered backend.

SharedFactorPortrait now declares the same covering boundary as its finite
accumulator, whose capacity and runtime active bound are checked by the backend.
Its retained acceptance checks require two bounded loops, each array's active
count, capacity64, and phase/modulus work inside its loop. Analytic-continuation
checks permit only operand-only selects; expensive work remains under control
flow. Surfer's existing decision-count check accepts either branches or selects.
The mock emitters and existing mock interpreter preserve branches and bounded
loops, with six active/capacity edge cases executed from ordinary checked source.
These are explicitly mock semantics, not a hardware instruction receipt.

Local verification on 9 October 2026 used official Idris2 v0.8.0 source
`15a3e4e70843f7a34100f6470c04b791330788df`: the official bootstrapped compiler
with the compiler API built and installed incrementally from that exact source.
The full monolithic self-hosted compiler build exceeded local memory; that build
is not claimed as completed. The declared hosted compiler/API producer remains
required at the published head.

`make check` passes: 41 semantic tests, actual source lowering, all retained
negative fixtures, F16/F32 checks, bounded loops, shared portrait, analytic
continuation, root search, six PowerVR primitive generators, renderer identity
gates, Mali mock smoke, nine target mock execution oracles and six bounded-loop
edge cases. Actual glslang15.1 validates and links the generated shader fixtures.
The ICK-built native runner selects the freshly emitted primitive shaders and
passes all six shader and six framebuffer checks under Mesa/llvmpipe.
The actual AArch64/API21 Android runner also links and has no COPY relocation.

Mesa execution is software-renderer evidence. No physical PowerVR, Mali,
phone/tablet performance, or other hardware acceptance is added by this change.
